Heat is not the same danger for everyone.

A water pill, a beta blocker, an antipsychotic, multiple sclerosis, a spinal cord injury, dialysis: each changes how a body sheds heat, and the forecast does not know any of it. Sudor reads the live forecast for one address and answers for that person. When to go out today. What to do when it cannot wait. What the warning signs mean, and when to call 911.

How it works

      
Four decisions shape everything else.

    

    

      

        
It answers for one body, not for a city

        

          The same 96 degrees is a fine afternoon for one person and a hospital visit for another. Medications are
          matched to the way they act, sweating less, holding less water, a heart that cannot speed up, and conditions
          are matched to how they break the body's cooling, so the answer says which one is driving the risk.
        

      

      

        
The weather is polled, never fetched mid answer

        

          One forecast call takes about half a second on its own, which is the entire budget for a voice turn. So each
          registered place is refreshed on a background timer and every answer is served from memory.
        

      

      

        
A home is not a private room

        

          An aide, a neighbour or a grandchild may be listening. In privacy mode the answer says that something in the
          health profile makes the heat riskier, without naming it, and holds personal precautions until they are
          asked for. The heat stroke line is never held back.
        

      

      

        
It learns only in the safe direction

        

          Saying you felt unwell out there sets that heat index as your limit from then on. Saying you felt fine never
          loosens it, because one comfortable afternoon is not evidence the next one is safe.
        

      

    

  


  

    

      
What it will not do

      
The honest list. This one matters more than most, because people act on it.

    

    
    
      
  • It is not a doctor and not medical advice. It never tells anyone to stop, start or change a medication. It says to ask a doctor or pharmacist.
    • 
      
  • Heat stroke goes to 911 first. Confusion, slurred speech or collapse gets the emergency line before anything else, and family are emailed after.
    • 
      
  • It will not guess. If the weather service is unreachable it says so.
    • 
      
  • It cannot speak first. An add-on answers when called, so the evening warning for tomorrow goes to confirmed contacts by email instead.
    • 
      
  • Places are US only, because Alexa+ is.
    • 
      
  • The stand-in profile is temporary. It belongs to this browser and is cleared when the server restarts.
    •

Run it yourself

      
Node 20 or newer. No keys, no accounts, no paid services.

    

    
git clone https://github.com/nirbhay221/sudor
cd sudor
npm install
npm run build
node dist/server.js        # serves this page and the MCP endpoint on 8789

    
Or, with nothing installed but Docker: docker build -t sudor . && docker run -p 8789:8789 sudor

    
Call a tool the way a host would:

    
curl -s http://localhost:8789/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"weather_check","arguments":{}}}'
